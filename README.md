# About this repository

I decided around November 2024 to get into using the Godot Game Engine, because I wanted some kind of project that would expose me to a lot of different things outside of school. There are a lot of things that I got exposed to, such as Graph Theory, dictionaries, reading documentation, creating shaders, procedural generation, the usefulness of JSON files, and a lot more. However, I also did not know anything about creating software development plans, using Git, or really using any kind of version control system at all. 

I haven't touched the code or files in here since the start of the spring semester of 2025, but after learning the importantance of using Git and creating documentation, not just reading or using it, I realize that I really didn't know anything while making any of the code in here. I will re create this repository at some point in the future, but if anyone comes across this and tries to make sense of how it is structured, I can only say I am sorry.

That said, here are all of the things that I feel I learned while making programs in the Godot Engine:
- GDScript
- GLSL shader language ([The Book of Shaders](https://thebookofshaders.com) is a very good resource for learning GLSL)
- Dictionaries
- Graph Theory
- JSON file usage
- File I/O
- How to read documentation, such as [Godot's documentation](https://docs.godotengine.org/en/stable/)
